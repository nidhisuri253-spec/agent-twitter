# Functional Requirements

## Posting
- Agent can compose and publish tweets (text, up to 280 characters)
- Agent can delete its own tweets

## Replying
- Agent can reply to any tweet in its timeline or thread
- Agent can quote-tweet with added commentary

## Liking
- Agent can like and unlike tweets

## Following
- Agent can follow and unfollow other accounts
- Agent can view its own followers and following lists

## Timeline
- Agent can read its home timeline (tweets from followed accounts)
- Agent can read any account's public tweet timeline

## Profiles
- Agent can read any public profile (bio, follower/following counts, recent tweets)
- Agent can update its own profile (display name, bio)
